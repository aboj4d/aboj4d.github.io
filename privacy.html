نطاق السياسة والمسؤول عن التطبيق

تصف هذه السياسة معالجة البيانات في تطبيق بوابة حلفايا وخادمه وهذا الموقع التعريفي. تتولى إدارة بوابة حلفايا تشغيل التطبيق، ويمكن التواصل معها على halfaya.gate.support@gmail.com.

الموقع يشرح وظائف التطبيق ولا يتيح تسجيل الدخول أو إدخال بيانات الحساب. يمكنك تصفح المحتوى العام في التطبيق دون إنشاء حساب.

حالة ميزات الحساب: تسجيل الدخول بالهاتف متاح. توثيق البريد والاستعادة بالبريد، ثم الدخول الاختياري عبر Google، قيد الإعداد والاختبار. توضح الفقرات الخاصة بها المعالجة المقصودة عند تفعيلها؛ لا تعني أنها تعمل حالياً. ستُحدّث هذه السياسة وحالة الخدمة عند التفعيل.

البيانات التي نعالجها ولماذا

  • بيانات الحساب: الاسم ورقم الهاتف وبيانات الملف الشخصي التي تقدمها، والبريد إن أضفته، ومعرّف الحساب وحالته وصلاحياته. نستخدمها لتسجيل الدخول وإدارة الحساب والنشر والتواصل بشأن الخدمة. إضافة بريد إلى حقل قديم لا تجعله موثقاً تلقائياً.
  • كلمات المرور والجلسات: يحفظ الخادم تجزئة كلمة المرور للتحقق منها، ولا يتيح استرجاع كلمة المرور الأصلية. يحتفظ التطبيق برمز الجلسة على الجهاز لتسجيل الدخول.
  • المحتوى والمرفقات: النصوص والصور والفيديو وبيانات جهات الاتصال والعناوين وروابط الخرائط التي تختار رفعها، لإظهارها في الأقسام المقصودة ومراجعتها وإدارتها.
  • التفاعل والمساعدة: الإعجابات والمفضلة والبلاغات وطلبات الدعم واستعادة الحساب، لتقديم الوظائف ومعالجة الأخطاء والإساءة. لا تضع كلمة مرور أو رمز تحقق أو بيانات طبية حساسة في نصوص الدعم والمنشورات.
  • بيانات التشغيل والأمان: معلومات الطلبات والأخطاء وأحداث الإدارة والأوقات ومعرفات السجلات. قد يعالج الخادم ومقدمو الاستضافة عنوان IP ومعلومات تقنية عن الطلب للحماية وتشغيل الخدمة وتحديد معدل المحاولات.

اختيار الصور أو الملفات يتم بناءً على إجراء منك. لا يتطلب التصميم الحالي قراءة دفتر جهات الاتصال أو جمع موقع GPS في الخلفية؛ العنوان أو رابط الخريطة يُدخل اختيارياً ضمن المحتوى.

ما الذي قد يظهر للآخرين؟

المحتوى المنشور وبيانات الدليل العام ووسائل الاتصال والعناوين والصور التي تُدرج فيه قابلة للمشاهدة بحسب القسم وحالة النشر. وقد يظهر اسم صاحب المحتوى. تأكد من امتلاكك حق نشر معلومات الأشخاص وصورهم.

تُحفظ المرفقات العامة في مساحة Supabase Storage عامة؛ من يملك رابط الملف قد يستطيع عرضه، بما في ذلك عندما لا يكون السجل منشوراً بعد. لذلك لا ترفع وثائق هوية أو أسراراً أو صوراً خاصة. حذف رابط من واجهة أو سجل لا يضمن وحده حذف الملف من التخزين أو إزالة نسخ سبق أن احتفظ بها آخرون.

يصل المطور والمشرفون المخولون إلى البيانات اللازمة للمراجعة والإدارة ضمن صلاحياتهم. لا تُعرض كلمات المرور أو رموز الاستعادة للعموم.

الاستضافة والخدمات الخارجية

  • Render وPostgreSQL: تشغيل API وحفظ الحسابات والسجلات والمحتوى وبيانات الإدارة.
  • Supabase Storage: حفظ الصور والمرفقات العامة وتقديم روابط عرضها.
  • GitHub Pages: استضافة الموقع التعريفي وصفحات الخصوصية والشروط عند نشره. قد تعالج GitHub بيانات الزيارة التقنية وفق سياسة خصوصيتها.
  • البريد: يُجهّز Gmail API لإرسال رسائل الأمان من حساب دعم المنصة. Brevo خيار بديل، ويُعلن عنه ويُحدّث هذا النص قبل استخدامه فعلياً.
  • الخرائط والاتصال والمشاركة: عندما تختار فتحها ينتقل الطلب إلى التطبيق أو الخدمة التي اخترتها، وتطبق سياسة تلك الخدمة.

قد تعالج هذه الخدمات البيانات في دول خارج بلدك. نشارك معها ما يلزم لتقديم الوظيفة. لا نستخدم بيانات Google لبيعها أو للإعلانات المخصصة أو لتدريب نماذج ذكاء اصطناعي.

هذا الموقع ثابت، ولا يحتوي نماذج حساب أو أدوات تحليلات أو ملفات تعريف ارتباط نضيفها نحن. الخط والصور مستضافة مع صفحاته؛ سجلات الاستضافة الخاصة بمقدم الخدمة تبقى خاضعة لسياسته.

استخدام Gmail API وبيانات Google

إرسال رسائل الأمان من بريد المنصة

الغرض المقصود من صلاحية gmail.send هو إرسال رموز توثيق البريد واستعادة الحساب من حساب Gmail المخصص لدعم بوابة حلفايا. يمنح مالك بريد الدعم الإذن للخادم؛ لا يُطلب من مستخدم التطبيق تفويض قراءة بريده أو الإرسال منه لاستلام رمز. تستقبل Google عنوان المستلم ومحتوى الرسالة لإرسالها.

هذه الصلاحية لا تمنح قراءة صندوق الوارد أو جهات الاتصال أو Google Drive. تُحفظ اعتمادات التفويض في إعدادات الخادم المحمية، ولا تُضمّن في APK أو الموقع. يستطيع مالك بريد الدعم إلغاء التفويض من اتصالات حساب Google، وعندها يتوقف الإرسال حتى إعادة تهيئته.

توثيق البريد والاستعادة

عند تفعيل الخدمة، يُستخدم البريد الذي تثبت ملكيته للدخول والاستعادة. رموز التحقق محدودة الصلاحية ولمرة واحدة مع حدود للمحاولات والإرسال. تُخزن قيمة تحقق محمية؛ وقد تحفظ قائمة إرسال الخادم محتوى الرسالة مشفراً مؤقتاً إلى أن تُرسل أو تنتهي. رموز الاستعادة الاحتياطية لا تُحفظ بصيغتها القابلة للاستخدام، ويجب أن تحتفظ بنسختك في مكان آمن.

الدخول عبر Google — مرحلة لاحقة

عند إطلاقه، سيكون اختيارياً. سيُطلب إثبات هوية Google ومعلومات الملف الأساسية اللازمة للدخول، مثل معرّف Google الثابت والاسم والبريد الموثق والصورة إن وُجدت. لا تُطلب صلاحية Gmail من المستخدم لهذا الغرض. لا يُدمج حساب موجود تلقائياً لمجرد تطابق بريد، ويحتاج الربط إلى جلسة موثوقة وإثبات الملكية.

استخدام بوابة حلفايا للبيانات المستلمة من Google APIs ونقلها إلى أي تطبيق آخر يلتزمان بـ سياسة بيانات المستخدم لخدمات Google API، بما فيها متطلبات الاستخدام المحدود. لا تُستخدم هذه البيانات لغرض خارج الوظيفة المعلنة أو تُتاح للقراءة البشرية إلا بموافقة المستخدم أو للضرورة الأمنية أو القانونية وفق تلك السياسة.

الحفظ والحماية

نحتفظ ببيانات الحساب والمحتوى ما دامت لازمة لتقديم الخدمة وإدارة الحساب. لا توجد حالياً مدة موحدة منشورة للحذف التلقائي لكل السجلات؛ قد نحتفظ بما يلزم لمعالجة إساءة أو نزاع أو التزام قانوني، وتُراجع طلبات الحذف بحسب نوع البيانات وحقوق الآخرين. قد تبقى نسخ لدى مقدمي الخدمة وفق مددهم وسياساتهم.

نستخدم صلاحيات وصول وتجزئة لكلمات المرور واتصال HTTPS في الخدمة المنشورة، ونقيد وسائل الاستعادة. لا يمكن ضمان منع كل خطأ أو وصول غير مشروع. أبلغ الدعم إذا اشتبهت باختراق حسابك، ولا ترسل كلمة مرورك أو رموزك.

الوصول والتصحيح وحذف البيانات

يمكنك تعديل الحقول المتاحة لك من التطبيق. لطلب الوصول إلى بياناتك أو تصحيحها أو حذف حسابك أو محتوى أو مرفق، راسل halfaya.gate.support@gmail.com مع وصف الطلب ومعرّف السجل إن كان متوفراً، ودون أسرار. طلب حذف الحساب يعالج عبر الدعم حالياً؛ قد نطلب إثبات ملكية مناسباً قبل أي إجراء لحماية صاحب الحساب. لا نعد بدمج حسابات أو نقل ملكيتها بناءً على الاسم أو وسيلة تواصل غير موثقة.

بعد إطلاق إدارة وسائل الاستعادة، ستظهر الخيارات المفعلة في إعدادات الحساب. إلغاء تفويض Google لا يحذف حساب بوابة حلفايا أو منشوراته تلقائياً؛ اطلب حذفها بشكل منفصل إن أردت ذلك.

التطبيق موجه للمجتمع العام، ولا يستهدف جمع بيانات الأطفال. إذا أُدرجت بيانات طفل دون حق أو موافقة مناسبة، أبلغنا لمراجعتها.

Privacy summary

Halfaya Gate is operated by the application administration, reachable at halfaya.gate.support@gmail.com. Account details, user-submitted content, public contact listings, interactions, support requests and technical security records support the application. Passwords are hashed. Public media is stored in a public Supabase Storage bucket; possession of a file URL may allow access even before its record is published. Render/PostgreSQL run the API and database. GitHub Pages hosts this static informational site when published; no analytics scripts, account forms or application cookies are included here.

Email verification/recovery and optional Google sign-in are being prepared, not yet active. The proposed Gmail API integration uses only gmail.send, authorized by the platform support mailbox owner, to send verification and recovery messages. App users do not grant mailbox access to receive a code. It does not read inboxes, contacts or Drive. Optional Google sign-in will use identity and basic profile information, with no automatic account merging. Google API data use and transfers will comply with the Google API Services User Data Policy, including Limited Use. It is not sold or used for personalized ads or AI training.

Request access, corrections, account deletion or media removal through the support address; ownership may need to be verified. Public content and provider backups may have separate retention needs. Revoking Google authorization does not itself delete a Halfaya account. The full Arabic policy above describes current processing and planned features separately.
